# Music Triad — Student Practice

A browser-based rhythm game for classroom practice.

## Play locally
Open `index.html` in Chrome.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `music-triad`.
2. Upload `index.html` (and this README if you want).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the public Pages address. Post that link in Google Classroom.

No student login or server is required for the game itself.
